変数

好感度やフラグなど、ゴーストが覚えておく値です。終了時に自動で保存されます。

チェック

おかしなところを探します。クリックすると、そのブロックまで移動します。

さがす

セリフ・変数・トーク名などから探します（Ctrl+F）。 クリックすると、そのブロックまで移動します。

立ち絵

用意した PNG を番号ごとに割り当てられます。えらばなかった番号は、下の「見た目（仮シェル）」の色で自動生成します。

surface0.png のような番号の絵を、その番号に割り当てます。うごき（SERIKO）と当たり判定は読みこみません。

見た目（仮シェル）

絵を用意していないときは、この色でかんたんな立ち絵を自動生成します。

バルーン（吹き出し）

「バルーンも作る」を入れると、この色のかんたんな吹き出しを同梱します。 入れないと、使う人が持っているバルーンで表示されます。

うごき（アニメーション）

立ち絵をパラパラ切りかえて動かします。こまは左から順に出ます。「うごき N を再生する」ブロックで呼べます。

名前と作者

ゴーストが自分で言うこと（ブロックを置いていないイベントの反応など）と、「いまごろ」「季節」「曜日の名前」の値、 readme.txt の言葉です。画面の言語とは別で、作りはじめたときの画面の言語になっています。

ランダムトーク

直近に出したトークを、この数だけ次の抽選からはずします。おまかせのときはトーク数の半分（最大8）です。

ネットワーク更新

ネットワーク更新に使う URL です。書き出したフォルダを丸ごと置く場所を、 うしろに / を付けて入れます。空ならネットワーク更新はしません。

SSP に入れる

SSP の ghost フォルダへ直接書き出して、そのまま切り替えます。

フォルダ／.nar に書き出す

手書きの YAYA ゴーストにつなぐ

YAYA で手書きしたゴーストに、ブロックを足せます。つないでいるあいだは、書き出すとそのゴーストに書きこみ、スタジオのファイル（studio_runtime.dic と studio_program.dic）と yaya.txt の印の行のほかには触りません。

読み込み

書き出し済みのゴースト（ghost.json）を読み込んで編集できます。

つかいかた

  1. トークの左のイベントから「起動したとき」などをキャンバスにドラッグします。
  2. その下にセリフの「…と話す」ブロックをつなげます。
  3. 右のためすの ▶ で動きを確認します。
  4. なでられたときなどのマウスのイベントは、あたま・かお・むねといった場所ごとに 分けて反応させられます（仮シェルにも当たり判定が入っています）。
  5. 右のチェックに気になるところが出ます。クリックするとその場所へ移動します。
  6. 用意した絵を使うときは、キャラと絵の「立ち絵」で PNG をえらびます。
  7. 書き出しでフォルダか .nar を作り、SSP にドラッグ＆ドロップで入れます。

キーボードだけでも組めます。/ で名前をさがして Enter で置くと、えらんでいるブロックのすぐ下につながります。 置いたブロックの文字の欄にそのまま打てるので、Enter で決めて、また / を押します。

ブロックの色

栞について

書き出したゴーストは yaya.dll（栞 YAYA）で動きます。ブロックは YAYA の辞書 ghost/master/studio_program.dic に書き出されます。SSP で動いているゴーストは、 「SSP に入れて動かす」で書き出すと、すぐ読み込み直されます。
